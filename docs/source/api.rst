API — Couche Intelligence
=========================

Documentation générée automatiquement depuis le schéma OpenAPI réel de l'API
FastAPI (``src/main.py``), qui héberge le graphe multi-agent LangGraph.

Pour régénérer le schéma après une modification des routes ou des modèles
Pydantic :

.. code-block:: bash

   uv run python docs/generate_openapi.py

.. note::
   Swagger UI interactif disponible en direct sur l'API en cours d'exécution :
   ``http://localhost:8000/docs`` (ou ``http://localhost:8020/docs`` via
   Docker Compose).
